Frequently asked questions

How long does it take to go live?–
Setup time depends on the number of call flows involved. We'll confirm a timeline during onboarding.
Which languages does the agent speak?+
Hindi, English, and Hinglish — including mid-sentence code-switching.
How does handoff to a human work?+
When the agent detects it needs to transfer, it passes the call along with full context so the customer doesn't repeat themselves.
What are the DND and consent rules?+
We follow TRAI regulations. DND lists are respected, and consent workflows are built into every campaign.
What happens if the agent gets stuck?+
The agent gracefully transfers to a human. It never guesses or makes up information.
